## Task: UIテーマシステム基盤構築

プロジェクト: ~/Desktop/quest-app/ (Next.js 16 + TailwindCSS v4 + Zustand)

### 目的
3つのUIテーマ（classic/modern/pop）を切り替えられるシステムを構築する。
現在は90年代RPG風（classic）のみ。若者にも刺さるよう modern/pop を追加。

### 実装内容

#### 1. 型定義の追加 (src/types/index.ts)

`UITheme` 型を追加:
```typescript
export type UITheme = 'classic' | 'modern' | 'pop';
```

`User` interfaceに追加:
```typescript
ui_theme: UITheme;
```

#### 3. ThemeProvider (src/components/ui/ThemeProvider.tsx)

```typescript
'use client';

import { useEffect } from 'react';
import { useUserStore } from '@/stores/userStore';

export function ThemeProvider({ initialTheme }: { initialTheme?: string }) {
  const theme = useUserStore((s) => s.user?.ui_theme) ?? initialTheme ?? 'classic';

  useEffect(() => {
    document.documentElement.setAttribute('data-theme', theme);
  }, [theme]);

  return null;
}
```

#### 4. userStoreにテーマ更新メソッド追加 (src/stores/userStore.ts)

UserStateに追加:
```typescript
setTheme: (theme: UITheme) => void;
```

実装:
```typescript
setTheme: (theme) =>
  set((state) => {
    if (!state.user) return state;
    return {
      user: { ...state.user, ui_theme: theme },
    };
  }),
```

#### 5. layout.tsxにThemeProvider追加

`src/app/layout.tsx` のbody内に `<ThemeProvider />` を追加。

### 重要な制約
- 既存の rpg-window クラスは残す（classic テーマで使用）
- CSS変数の上書きでテーマ切り替えを実現（コンポーネント変更を最小限に）
- :root の変数はデフォルト（classic）として残す
- data-theme属性がない場合はclassicがデフォルト
- TypeScriptの型安全性を維持する
- UITheme型のimportは `@/types` から行う
