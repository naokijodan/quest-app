## 4. Requirements（仕様）

### (main)/layout.tsx
- Server Component
- getUserProfile()でユーザー情報取得
- 未認証→/login、オンボーディング未完了→/onboarding にリダイレクト
- シンプルなヘッダー: アプリ名「Quest App」+ ユーザー名 + レベル表示
- children をレンダリング
- max-w-4xl, mx-auto, padding

### (main)/page.tsx — ホーム画面
- Server Component
- getPresetQuests() でクエスト一覧取得
- getUserProfile() でユーザー情報取得
- 「クエストを選ぼう！」タイトル
- カテゴリ別にグループ分け（basic → business → life → creative → analysis）
- ロックされたカテゴリはグレーアウト+ロックアイコン
- 各クエストは QuestCard コンポーネントで表示

### QuestCard.tsx
- Props: quest: PresetQuest, locked: boolean
- カード表示: icon, title, description, difficulty(★表示), xp_reward, category badge
- locked=true の場合: opacity-50, ロックオーバーレイ, クリック不可
- locked=false の場合: Link to /quest/[id]
- ホバーエフェクト

### quest/[id]/page.tsx
- Server Component でクエスト情報取得
- クエストが存在しない場合は notFound()
- QuestInputForm をレンダリング

### QuestInputForm.tsx（'use client'）
- Props: quest: PresetQuest
- quest.required_inputs に基づいて動的にフォームを生成
  - type: 'text' → Input コンポーネント
  - type: 'textarea' → Textarea コンポーネント
  - type: 'select' → <select> ドロップダウン
- バリデーション: required, minLength, maxLength をリアルタイムチェック
- 「クエスト実行！」ボタン → useQuestExecution フックを呼び出し
- 実行中は QuestExecution コンポーネントを表示
- 完了後は QuestResult コンポーネントを表示
- ステートマシン: 'input' | 'executing' | 'completed' | 'error'

### useQuestExecution.ts
```typescript
// SSEストリーミング接続を管理するカスタムフック
// 1. fetch('/api/quest/execute', { method: 'POST', body, signal })
// 2. ReadableStream を読み取り
// 3. SSEイベントをパース（data: {...}\n\n）
// 4. questStore を更新（startExecution, appendContent, etc.）
// 5. uiStore でXPアニメーション, レベルアップモーダル表示
// 6. AbortController でキャンセル対応
// returns: { execute, cancel, phase: 'idle'|'executing'|'completed'|'error' }
```

### QuestExecution.tsx（'use client'）
- questStore から streamedContent, progressMessages を読み取り
- マスコット演出: 進捗メッセージをフキダシで表示
- ストリーミング中のテキストをリアルタイム表示
- 「キャンセル」ボタン
- ローディングアニメーション（pulse）

### QuestResult.tsx（'use client'）
- Props: questRunId, xpGained, levelUp
- 結果テキスト（streamedContent）をMarkdown風に表示
- XP獲得演出（+10 XP のバッジ）
- レベルアップ時はモーダル表示
- 「結果をコピー」ボタン（navigator.clipboard.writeText）
- 「もう一度実行」ボタン
- 「ホームに戻る」リンク

### SSE読み取りパターン
```typescript
const response = await fetch('/api/quest/execute', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ questId, inputs }),
  signal: controller.signal,
});

const reader = response.body!.getReader();
const decoder = new TextDecoder();
let buffer = '';

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  buffer += decoder.decode(value, { stream: true });
  const lines = buffer.split('\n\n');
  buffer = lines.pop() ?? '';
  for (const line of lines) {
    const data = line.replace(/^data: /, '');
    if (data) {
      const event: QuestSSEEvent = JSON.parse(data);
      // handle event...
    }
  }
}
```
