# Task: Phase2-CLIInstallGuide
# AI: Codex CLI
# Priority: High
# Risk Level: Low

## 1. Objective
Create a `/setup` page that guides users through installing CLI tools (Claude Code, Codex CLI, Gemini CLI) and setting up the Quest Agent. The page should show installation status for each CLI (using Agent health check) and provide step-by-step instructions.

## 2. Target Files
### Create
- `src/app/(main)/setup/page.tsx` — Server component wrapper
- `src/features/setup/components/CliSetupGuide.tsx` — Client component with interactive installation status

### Modify
- `src/app/(main)/layout.tsx` — Add "セットアップ" nav link
- `src/features/quest/components/AgentStatusBanner.tsx` — Add link to /setup page in disconnected/error states

## 3. Dependencies (must read first)
- `src/app/(main)/layout.tsx` — Current layout with nav
- `src/components/ui/Button.tsx` — Button component
- `src/components/ui/Card.tsx` — Card, CardHeader, CardTitle, CardDescription

### 4.2 src/features/setup/components/CliSetupGuide.tsx
Client component that:
1. Checks Agent health on mount (using `getAgentClient().checkHealth()`)
2. Displays 3 sections:
   - **Step 1: CLIツールのインストール** — Shows cards for each CLI (Claude Code, Codex CLI, Gemini CLI) with:
     - Name, description, install command
     - Status indicator: installed (green) / not installed (gray) — based on Agent health `available_tools`
     - At least one CLI must be installed
   - **Step 2: Quest Agentの起動** — Shows the command to start the agent and current connection status
   - **Step 3: 準備完了！** — Green checkmark when both agent connected and at least 1 CLI available

CLI installation info:
- **Claude Code**: `npm install -g @anthropic-ai/claude-code` — Anthropicの公式CLI。Claude Proサブスク（月額$20）が必要。
- **Codex CLI**: `npm install -g @openai/codex` — OpenAIの公式CLI。ChatGPT Proサブスク（月額$20）が必要。
- **Gemini CLI**: `npm install -g @anthropic-ai/gemini-cli` — (まだ利用不可 — 今後対応予定)

Agent start command: `cd packages/quest-agent && npm run dev`

Use these icon imports from lucide-react: `Terminal, CheckCircle, Circle, Download, ArrowRight, RefreshCw, Settings`
