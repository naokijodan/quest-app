## 4. Requirements（仕様）

### src/lib/anthropic/client.ts
```typescript
// Anthropic SDK のシングルトン初期化
// process.env.ANTHROPIC_API_KEY を使用
// エラーハンドリング: APIキー未設定時のわかりやすいエラー
import Anthropic from '@anthropic-ai/sdk';

let client: Anthropic | null = null;
export function getAnthropicClient(): Anthropic {
  if (!client) {
    const apiKey = process.env.ANTHROPIC_API_KEY;
    if (!apiKey) throw new Error('ANTHROPIC_API_KEY is not configured');
    client = new Anthropic({ apiKey });
  }
  return client;
}
```

// prompt_template の {{variable}} を実際の入力値で置換

### src/app/api/quest/execute/route.ts （CRITICAL）
POST ハンドラー。以下の手順で処理する:

1. **認証チェック**: Supabase auth.getUser()
2. **リクエストバリデーション**: questExecuteSchema.safeParse
3. **クエスト取得**: preset_quests テーブルから quest を取得
4. **カテゴリアクセスチェック**: ユーザーのレベルに基づくカテゴリ制限
5. **デイリークォータチェック**: user_daily_quotas テーブル確認（Free: 10回/日, 10000トークン/日）
6. **quest_run 作成**: status: 'running' で INSERT
7. **SSE ストリーム開始**: `start` イベント送信
8. **Anthropic API ストリーミング呼び出し**: delta イベントを順次送信
9. **進捗メッセージ**: 途中で `progress` イベントを送信（マスコットのセリフ）
10. **完了処理**:
    - quest_run を 'completed' に更新、output_data・tokens保存
    - XP加算: users テーブルの experience_points を更新
    - レベルアップ判定
    - user_daily_quotas のカウント更新
    - `complete` イベント送信
11. **エラー時**: partial_output を保存、quest_run を 'failed' に更新、`error` イベント送信

SSEフォーマット:
```
data: {"type":"start","quest_run_id":"uuid"}\n\n
data: {"type":"delta","content":"テキスト"}\n\n
data: {"type":"progress","message":"がんばってるにゃ！"}\n\n
data: {"type":"complete","quest_run_id":"uuid","xp_gained":10,"level_up":false}\n\n
```

レスポンスヘッダー:
```
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive
```

## 7. High-Risk Area Details

### SSE Streaming
- Endpoint: POST /api/quest/execute
- Event format: QuestSSEEvent 型に厳密に従う
- エラー時: partial_output を保存、status を 'failed' に更新
- AbortController 対応: クライアント切断時にクリーンアップ
- ReadableStream の new Response() で返す

### Daily Quota (user_daily_quotas テーブル)
```sql
CREATE TABLE user_daily_quotas (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  quota_date DATE NOT NULL DEFAULT CURRENT_DATE,
  api_calls_made INTEGER NOT NULL DEFAULT 0,
  tokens_used INTEGER NOT NULL DEFAULT 0,
  last_reset_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE (user_id, quota_date)
);
```
- 存在しない場合は INSERT、存在する場合は UPDATE
- Free plan: 10 calls/day, 10000 tokens/day
